## 🏷️ ПРАВИЛА ВЕРСИОНИРОВАНИЯ:

### Схема версий:
- **Версия проекта**: `V1.0.0` (MAJOR.MINOR.PATCH) - общая для всех файлов проекта
- **Дата релиза**: `YYYY.MM.DD` - индивидуальная для каждого файла

### Формат в файлах:
```bash
# Версия проекта: V1.0.0
# Дата релиза: YYYY.MM.DD
```

### Правила обновления:
1. **При изменении функциональности проекта** → обновляем версию проекта во ВСЕХ файлах
2. **При изменении конкретного файла** → обновляем дату релиза ТОЛЬКО в этом файле
3. **При изменении правил ASSISTANT_RULES.md** → обновляем версию проекта во ВСЕХ файлах
4. **MAJOR версия** - кардинальные изменения архитектуры
5. **MINOR версия** - новые функции, улучшения
6. **PATCH версия** - исправления ошибок

## 🎯 ОСОБЕННОСТИ ПРОЕКТА FSA-3dsMaxAutomation:

### Основные файлы:
- `apartment_model.py` - модель данных квартиры
- `max_script_generator.py` - генератор MAXScript
- `apartment_gui.py` - графический интерфейс
- `start_gui.py` - точка входа

### Технологии:
- **Python 3.8+** с tkinter для GUI
- **MAXScript** для 3ds Max
- **JSON** для сохранения проектов
- **Git** для версионирования

### Принципы разработки:
- **Простота** - минимальные зависимости
- **Надежность** - проверка синтаксиса после каждого изменения
- **Документированность** - подробные README файлы
- **Версионирование** - четкая схема версий
- **Кроссплатформенность** - работа на Windows, macOS, Linux

## 🔧 СПЕЦИФИКА ПРОЕКТА:

### Работа с 3ds Max:
- Генерация MAXScript для автоматизации
- Преобразование метров в единицы 3ds Max (см)
- Создание геометрии: Box, Walls, Floor, Ceiling
- Автоматическое назначение материалов

### Модель данных:
- `ApartmentModel` - основной класс квартиры
- `Room` - модель комнаты с параметрами
- `Wall` - модель стены с проемами
- `Opening` - проемы (двери, окна, арки)

### GUI интерфейс:
- Вкладки: Основные настройки, Комнаты, Стены, Предпросмотр
- Управление проектами (создание, сохранение, загрузка)
- Редактирование комнат и элементов
- Предпросмотр MAXScript
