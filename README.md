**Разработчик: @FoksSegr**

## Описание проекта

FSA-3dsMaxAutomation - это система автоматизации создания 3D моделей планировок квартир в 3ds Max. Приложение позволяет быстро создавать планировку, добавлять комнаты, двери, окна и автоматически генерировать 3D модель в формате 3ds Max.

### Основные возможности:

- 🏠 **Создание планировки** - быстрое добавление комнат с размерами
- 🚪 **Управление проемами** - добавление дверей и окон
- 🎨 **Настройка материалов** - автоматическое назначение материалов
- 📤 **Экспорт в MAXScript** - генерация скрипта для 3ds Max
- 💾 **Сохранение проекта** - работа с файлами JSON
- 🖥️ **Графический интерфейс** - удобный GUI на tkinter

## Использование

### 1. Создание новой планировки

1. Запустите приложение
2. На вкладке "Основные настройки" укажите название проекта и высоту потолка
3. Перейдите на вкладку "Комнаты"
4. Нажмите "Добавить комнату"
5. Заполните параметры комнаты:
   - Название
   - Тип комнаты (living, bedroom, kitchen, bathroom, hallway)
   - Ширина и длина в метрах
   - Координаты X, Y

### 2. Добавление комнат

- Используйте кнопку "Добавить комнату" для создания новых комнат
- Каждая комната автоматически получает 4 стены
- Вы можете редактировать комнаты или удалять их

### 3. Генерация MAXScript

1. После добавления комнат перейдите на вкладку "Предпросмотр"
2. Нажмите "Генерировать 3D модель" или "Показать MAXScript"
3. MAXScript будет отображен в окне предпросмотра
4. Сохраните скрипт или экспортируйте в .max файл

### 4. Использование в 3ds Max

1. Откройте 3ds Max
2. Нажмите `MAXScript` → `Run Script...`
3. Выберите сохраненный .ms файл
4. Скрипт автоматически создаст 3D модель квартиры

## Особенности

- **Автоматическое создание стен** - для каждой комнаты создается 4 стены
- **Генерация пола и потолка** - автоматически для каждой комнаты
- **Масштабирование** - корректное преобразование метров в единицы 3ds Max
- **Материалы** - автоматическое назначение базовых материалов
- **Сохранение проекта** - работа с JSON форматом

## Примеры использования

### Создание простой квартиры

```python
from apartment_model import ApartmentModel, Room
from max_script_generator import MaxScriptGenerator

# Создание модели квартиры
apartment = ApartmentModel("Моя квартира", ceiling_height=2.7)

# Добавление спальни
bedroom = Room(
    name="Спальня",
    x=0, y=0,
    width=3.5, length=4.0,
    room_type="bedroom"
)
bedroom.add_window(width=1.5, height=1.5, position=0.5)
bedroom.add_door(width=0.9, height=2.1, position=0.3)

apartment.add_room(bedroom)

# Генерация MAXScript
generator = MaxScriptGenerator(apartment)
generator.generate_full_apartment()

# Сохранение
generator.save_to_file("apartment.ms")
```

### Загрузка из JSON

```python
from apartment_model import ApartmentModel
import json

# Загрузка из файла
with open("apartment.json", 'r') as f:
    data = json.load(f)
    apartment = ApartmentModel.from_dict(data)

# Генерация
generator = MaxScriptGenerator(apartment)
generator.generate_full_apartment()
generator.save_to_file("apartment.ms")
```

## Разработка

### Структура модулей

1. **apartment_model.py** - Модель данных
   - `ApartmentModel` - основной класс квартиры
   - `Room` - модель комнаты
   - `Wall` - модель стены
   - `Opening` - проемы (двери, окна)

2. **max_script_generator.py** - Генератор скриптов
   - `MaxScriptGenerator` - преобразование модели в MAXScript
   - Генерация геометрии, материалов, освещения

3. **apartment_gui.py** - Интерфейс
   - `ApartmentGUI` - главное окно приложения
   - Управление проектами, комнатами, стенами
